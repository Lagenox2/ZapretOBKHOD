# ZapretOBKHOD

Локальный обход DPI-блокировок для Windows 10 **без VPN и без зарубежных серверов**.

Программа не перенаправляет трафик: соединения с сайтами идут напрямую через вашего
провайдера. На этом компьютере лишь корректируются некоторые пакеты (разделение TLS,
фейковые пакеты для DPI), чтобы оборудование провайдера не распознавало запрещённый
протокол. Всё работает локально.

---

## Быстрый старт

1. Распакуйте архив **целиком** (не запускайте exe прямо из ZIP).
2. Запустите `ZapretOBKHOD.exe` и подтвердите запрос прав администратора.
   Права нужны драйверу WinDivert, который перехватывает пакеты локально.
3. Выберите профиль (по умолчанию — **Комбо: YouTube + Discord + Telegram**).
4. Нажмите **«Включить обход»**.
5. Проверьте доступ кнопкой **«Проверить»**.

Остановить обход — кнопка **«Выключить обход»**. Закрытие окна сворачивает программу
в трей; полностью выйти можно через меню значка в трее → **«Выход»**.

---

## Профили

| Профиль | Для чего |
|---|---|
| **Комбо: YouTube + Discord + Telegram** | Рекомендуется. Обход только для этих сервисов. |
| **Только YouTube** | YouTube и Google Video. |
| **Только Discord** | Сайт, клиент и вложения Discord. Голос — по возможности, зависит от провайдера. |
| **Telegram + весь HTTPS** | Telegram не всегда передаёт домен открыто, поэтому обрабатывается весь HTTPS, кроме исключений. |
| **Соцсети и медиа** | Instagram, Facebook, X/Twitter, Rutracker, Spotify и др. |
| **Все сайты (агрессивно)** | Весь HTTP/HTTPS/QUIC, кроме банков и госуслуг. |
| **Мягкий режим** | Только разделение TLS-пакетов, без подмены. Самый безопасный. |
| **Свой список** | Домены из `lists\custom.txt`. |

Если не работает — попробуйте другой профиль. Разные провайдеры используют разные DPI,
поэтому универсального рецепта нет.

Сменить профиль или галочки можно и при включённом обходе: программа сама перезапустит
движок с новыми параметрами (на несколько секунд связь может прерваться).

## Свои сайты

Откройте `lists\custom.txt` (кнопка **«Списки»** в журнале), добавьте домены по одному
на строку:

```
example.com
blocked-site.org
```

Поддомены учитываются автоматически. Затем выберите профиль **«Свой список»**.

Исключения (банки, госуслуги, российские сервисы) лежат в `lists\exclude.txt`.
Галочка **«Не трогать банки и госуслуги»** включает этот список.

---

## Автозапуск

Галочка **«Запускать при входе в Windows»** создаёт задачу в Планировщике Windows
с наивысшими правами. При входе программа стартует без запроса UAC, сворачивается в трей
и сразу включает обход.

Отключить автозапуск можно той же галочкой. Задача называется `ZapretOBKHOD`.

---

## Дополнительно

* **Принудительно TCP (блокировать QUIC)** — добавляет правило брандмауэра, блокирующее
  UDP/443. Браузеры переходят на TCP, где обход работает стабильнее. Может пригодиться,
  если YouTube тормозит.
* **Сворачивать в трей** — закрытие окна крестиком не выключает обход.
* **Проверка доступа** — HTTPS-запросы к YouTube, Discord и Telegram напрямую, без прокси.
  Красный индикатор означает, что соединение не установлено; жёлтый — сервер ответил,
  но с ограничением или медленно.

Журнал: `%LOCALAPPDATA%\ZapretOBKHOD\logs\`
Настройки: `%LOCALAPPDATA%\ZapretOBKHOD\settings.json`

## Если не работает

1. Посмотрите журнал в программе и файл лога.
2. Убедитесь, что запущены **от имени администратора** (UAC).
3. Закройте другие обходы: zapret, `winws`, GoodbyeDPI, Zapret2UI — они конфликтуют
   за WinDivert.
4. Антивирус может блокировать WinDivert. Добавьте папку программы в исключения.
5. Попробуйте профиль **«Все сайты (агрессивно)»** или **«Мягкий режим»**.
6. Проверьте, что путь к программе не содержит проблемных символов и папки `engine`
   и `lists` лежат рядом с exe.
7. Windows 10 должна быть x64 с обновлениями. На Windows 7 программа не тестировалась.

## Как это работает

`winws.exe` (движок проекта [zapret](https://github.com/bol-van/zapret)) через драйвер
[WinDivert](https://reqrypt.org/windivert.html) получает локальные пакеты, применяет
к ним техники DPI-обхода:

* разделение TLS ClientHello на несколько TCP-сегментов;
* изменение порядка сегментов;
* фейковые пакеты с некорректной контрольной суммой/sequence number;
* подмена QUIC Initial для UDP/443.

Ни один пакет не отправляется на сторонний сервер. VPN-туннеля нет. Маршрут трафика
не меняется.

Все компоненты используются без изменений и запускаются локально.

## Сборка из исходников

Нужен Windows 10 x64 и .NET Framework 4.8 (есть в системе по умолчанию).
Компилятор `csc.exe` входит в состав Framework.

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Результат: папка `dist\` и архив `ZapretOBKHOD-portable.zip`.

Исходники: `src\*.cs`, манифест `src\app.manifest`, иконка генерируется в `assets\app.ico`.
