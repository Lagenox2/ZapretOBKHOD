# ZapretOBKHOD для Android

Локальный обход DPI-блокировок на телефоне **без VPN-серверов и без зарубежных прокси**.

Программа не отправляет трафик на чужой сервер: все соединения идут напрямую через
вашего мобильного или домашнего провайдера. Приложение поднимает локальный туннель
`VpnService` только для того, чтобы пропустить пакеты через движок **ByeDPI** на самом
телефоне и применить к ним техники обхода DPI (разделение TLS, фейковые пакеты и т. п.).

> В строке состояния появится значок VPN — это нормально. Туннель замкнут на телефон,
> внешнего сервера за ним нет.

---

## Требования

* Android 5.0 (API 21) и выше.
* Телефон **не** должен быть рутован: root не нужен.
* Архитектура: arm64-v8a (почти все современные телефоны), armeabi-v7a, x86, x86_64.

---

## Установка

1. Скопируйте `ZapretOBKHOD.apk` на телефон.
2. Откройте файл в проводнике и разрешите установку из этого источника, если система
   спросит (Android 8+).
3. Запустите **ZapretOBKHOD**.
4. Нажмите большую кнопку **«Подключить»** и разрешите создание VPN-подключения.
5. Откройте YouTube, Discord или Telegram и проверьте работу.

Остановить обход — кнопка **«Отключить»** или значок в шторке уведомлений.

---

## Профили

При первом запуске в списке стратегий появляются готовые профили (закреплённые записи).
Выберите профиль в главном окне — приложение применит его сразу.

| Профиль | Для чего |
|---|---|
| **Комбо: YouTube + Discord + Telegram** | Рекомендуется. Обход только для этих сервисов. |
| **Только YouTube** | YouTube и Google Video. |
| **Только Discord** | Сайт, клиент и вложения Discord. |
| **Telegram + весь HTTPS** | Telegram не всегда передаёт домен открыто, поэтому обрабатывается весь HTTPS. |
| **Соцсети и медиа** | Instagram, Facebook, X/Twitter и другие. |
| **Все сайты (агрессивно)** | Весь HTTPS. Если другие профили не помогают. |
| **Мягкий режим (только разделение)** | Без фейковых пакетов. Самый безопасный вариант. |
| **Свой список сайтов** | Домены из списка `custom`. |

Если не работает — попробуйте другой профиль: у разных операторов разные DPI, поэтому
универсального рецепта нет.

Сменить профиль можно и при включённом обходе, соединение на пару секунд прервётся.

---

## Свои сайты и списки

В настройках приложения есть редактор списков доменов. Список **custom** изначально
содержит `example.com` — замените его своими доменами (по одному на строку) и выберите
профиль **«Свой список сайтов»**.

Встроенные списки (`youtube`, `googlevideo`, `discord`, `telegram`, `social`) обновляются
из ресурсов приложения при первом запуске и доступны для просмотра и правки.

---

## Автозапуск

В настройках:

* **«Запускать при включении устройства»** — запуск после перезагрузки телефона.
* **«Автоматическое подключение при старте ZapretOBKHOD»** — сразу поднимать туннель
  при запуске приложения.

На некоторых прошивках (Xiaomi, Huawei, Samsung) нужно дополнительно разрешить
автозапуск в системных настройках батареи и снять ограничение фоновой работы, иначе
система выгрузит службу.

---

## Если не работает

1. Убедитесь, что VPN-подключение действительно активно (значок в шторке).
2. Попробуйте профили **«Все сайты (агрессивно)»** и **«Мягкий режим»**.
3. Отключите другие VPN/обходы — одновременно может работать только один `VpnService`.
4. В настройках батареи разрешите приложению работу в фоне.
5. Проверьте, что в системе не включён «Private DNS» (DNS-over-TLS) — он может мешать.
6. Перезапустите телефон и попробуйте снова.

## Как это работает

Приложение — форк [ByeByeDPI](https://github.com/romanvht/ByeByeDPI) с движком
[ByeDPI](https://github.com/hufrea/byedpi) и транспортом
[hev-socks5-tunnel](https://github.com/heiher/hev-socks5-tunnel).

Схема полностью локальная:

```
приложение → локальный VpnService → ByeDPI (127.0.0.1) → провайдер → сайт
```

`VpnService` забирает трафик приложения в туннель на самом телефоне, ByeDPI применяет к
пакетам техники обхода и возвращает их в сеть. Ни один пакет не уходит на сторонний
сервер, маршрут до сайта не меняется.

## Сборка из исходников

Нужны JDK 17+ и Android SDK (platform 36, build-tools 34+).

```powershell
$env:JAVA_HOME='C:\dev\jdk\jdk-21.0.1'
$env:Path="$env:JAVA_HOME\bin;$env:Path"
.\gradlew.bat assembleDebug
```

Готовый APK: `app\build\outputs\apk\debug\app-debug.apk`.

Для release-сборки используется ключ `keystore\zapretobkhod.jks`; параметры подписи
берутся из `keystore.properties` (уже создан). Команда:

```powershell
powershell -ExecutionPolicy Bypass -File .\build-release.ps1
```

Скрипт собирает подписанный APK, проверяет подпись и кладёт его в `dist\ZapretOBKHOD.apk`.

> Сохраните файлы `keystore\zapretobkhod.jks` и `keystore.properties`: без них
> обновить уже установленное приложение поверх старой версии не получится —
> Android не примет APK, подписанный другим ключом.

Нативные библиотеки лежат в `app\src\main\jniLibs\<abi>\` и собраны из upstream-проектов;
NDK для сборки APK не требуется.

### Тесты

```powershell
powershell -ExecutionPolicy Bypass -File .\run-tests.ps1
```

Скрипт запускает JVM-юнит-тесты из временной копии проекта. Это обходной путь:
Kotlin-компилятор не читает classpath, если в пути есть символ `!`, — а путь к этой
папке как раз содержит длинную последовательность `!`. На сборку APK это ограничение
не влияет.
