# Пошаговая инструкция: ASUS RT‑N16, один кабель входит — один выходит

Эта инструкция для самого простого случая:

* в роутер включён **один кабель от провайдера**;
* из роутера выходит **один кабель к компьютеру**;
* интернет через роутер **уже работает**.

Мы ничего не меняем в настройках сети. Только добавляем обход DPI.

---

## Схема

```
 Кабель провайдера
        |
        v
  [ WAN / Internet ]  ASUS RT‑N16  [ LAN 1 ] ---- кабель ---- [ Компьютер ]
                                      [ LAN 2..4 ] — свободны
```

**Важно:** если интернет сейчас работает — **не перетыкайте кабели**.
Запомните, куда они вставлены, и оставьте как есть.

У RT‑N16 порт `WAN` обычно отдельный и другого цвета, порты `LAN 1–4`
стоят рядом. Кабель от провайдера должен быть в `WAN`, кабель к компьютеру —
в любом из `LAN`. Если у вас иначе (например, оба кабеля в LAN) — остановитесь
и напишите, схема будет другая.

---

## Что понадобится

1. Компьютер, который уже подключён к роутеру кабелем и имеет интернет.
2. Архив `dist\ZapretOBKHOD-router.zip` из этой папки проекта.
3. Программа **WinSCP** (удобнее всего) или PuTTY + любой SFTP‑клиент.
4. Пароль администратора роутера — тот, под которым вы заходите в его веб‑интерфейс.

---

## Шаг 1. Узнайте адрес роутера

Откройте браузер и зайдите в веб‑интерфейс роутера. Обычно это:

```
http://192.168.1.1
```

Если не открывается, в Windows нажмите `Win + R`, введите `cmd`, затем:

```
ipconfig
```

Найдите строку **Основной шлюз** (Default gateway) — это и есть адрес роутера.

Проверьте, что интернет работает **до всех действий**. Если нет — сначала
настройте роутер с провайдером, только потом продолжайте.

---

## Шаг 2. Включите JFFS и SSH

Зайдите в веб‑интерфейс роутера под паролем администратора.

**Tomato / TomatoUSB:**

* `Administration → JFFS` → поставить галочку **Enable JFFS**;
  галочку **Clean JFFS** — НЕ ставить;
* `Administration → SSH Daemon` → **Enable SSH Daemon**;
* нажмите **Save**, при запросе — перезагрузите роутер.

**DD‑WRT:**

* `Administration → JFFS2 Support` → **Enable**, Save & Apply;
* `Services → SSHd` → **Enable**, Save & Apply.

**OpenWrt:** обычно SSH уже включён, а JFFS — это обычный overlay.

**Стоковая прошивка ASUS:** найдите раздел с JFFS в дополнительных
настройках (`Advanced → System`). Если такой опции нет — используйте
Tomato или DD‑WRT, либо установка будет временной (в `/tmp`).

После включения подключитесь к роутеру по SSH (например, через PuTTY или
встроенный терминал WinSCP): адрес тот же, порт `22`, логин `admin`,
пароль — как у веб‑интерфейса.

---

## Шаг 3. Распакуйте архив на компьютере

Скачайте `ZapretOBKHOD-router.zip` и распакуйте его **целиком**.

Должна получиться папка:

```
ZapretOBKHOD-router
```

Внутри сразу видны файлы `install.sh`, `zapret.sh`, `config.sh`, папки
`bin`, `lists`, `web`. Если внутри всё ещё одна вложенная папка — распакуйте
ещё раз или скопируйте содержимое на один уровень выше.

Для примера положите её в `C:\ZapretOBKHOD-router`.

---

## Шаг 4. Скопируйте папку на роутер

### Через WinSCP (рекомендуется)

1. Откройте WinSCP → **New session**.
2. Заполните:
   * **File protocol:** `SCP`
   * **Host name:** `192.168.1.1` (или ваш адрес)
   * **User name:** `admin`
   * **Password:** пароль роутера
3. Нажмите **Login**. Если появится предупреждение о ключе — согласитесь.
4. Слева найдите папку `C:\ZapretOBKHOD-router`, справа перейдите в `/jffs`.
5. Перетащите папку `ZapretOBKHOD-router` мышкой в правую часть в `/jffs`.

Должно получиться:

```
/jffs/ZapretOBKHOD-router/install.sh
/jffs/ZapretOBKHOD-router/zapret.sh
```

### Через командную строку Windows

Если в Windows есть `scp`:

```
scp -r C:\ZapretOBKHOD-router admin@192.168.1.1:/jffs/
```

---

## Шаг 5. Установка

Откройте терминал на роутере (WinSCP: `Ctrl + T`, или PuTTY) и введите
**по одной строке**:

```sh
cd /jffs/ZapretOBKHOD-router
sh install.sh
```

Что должно появиться:

```
Установка в: /jffs/zapret-obkhod
Автозапуск: Tomato/ASUS (jffs2_exec).
Готово. Запуск: sh /jffs/zapret-obkhod/zapret.sh start
```

Возможные варианты второй строки: `DD-WRT (rc_startup)`, `OpenWrt`,
`Entware` — это нормально, значит прошивка распознана.

Если написано **«Автозапуск не распознан»** — это не ошибка. Программа
установлена, просто автозапуск придётся добавить вручную (см. шаг 9).

> Далее работаем **в папке `/jffs/zapret-obkhod`**, а не в той, откуда
> копировали. Если захотите поменять настройки — редактируйте
> `/jffs/zapret-obkhod/config.sh`.

---

## Шаг 6. Запуск

Введите две команды:

```sh
sh /jffs/zapret-obkhod/zapret.sh start
sh /jffs/zapret-obkhod/zapret.sh status
```

Пример правильного ответа:

```
ZapretOBKHOD включён: Комбо: YouTube + Discord + Telegram
Состояние: включён
Профиль: Комбо: YouTube + Discord + Telegram
Режим: tpws
LAN: br0
Web: http://192.168.1.1:81/
```

Если вместо «включён» появилось «выключен» — смотрите раздел «Если не работает»
ниже.

---

## Шаг 7. Проверьте с компьютера

1. Откройте те сайты, которые раньше не работали (YouTube, Discord).
2. Зайдите на `https://2ip.ru` — IP‑адрес должен остаться **вашего
   провайдера**. Никакого VPN и чужого сервера нет.
3. Если сайт всё ещё не открывается, смените профиль:

```sh
sh /jffs/zapret-obkhod/zapret.sh preset all
```

Программа сама перезапустится (связь на 1–2 секунды прервётся).

Другие профили: `youtube`, `discord`, `telegram`, `media`, `all`,
`soft`, `custom`.

---

## Шаг 8. Веб‑интерфейс (кнопки)

Откройте в браузере адрес, который показал `status`:

```
http://192.168.1.1:81/
```

Там по‑русски:

* **Включить**, **Выключить**, **Перезапустить**;
* кнопки профилей — **Комбо**, **YouTube**, **Discord**, **Telegram + HTTPS**,
  **Медиа**, **Все сайты**, **Мягкий**, **Свой список**;
* **Обновить** — показать текущее состояние.

Если страница не открылась, введите по SSH:

```sh
sh /jffs/zapret-obkhod/zapret.sh webstart
```

---

## Шаг 9. Чтобы включалось после перезагрузки

Перезагрузите роутер из веб‑интерфейса. Подождите 2–3 минуты, затем снова
подключитесь по SSH и проверьте:

```sh
sh /jffs/zapret-obkhod/zapret.sh status
```

Должно быть `Состояние: включён`.

Если выключено:

* проверьте, что JFFS включён и смонтирован:

```sh
mount | grep jffs
```

* проверьте hook автозапуска (Tomato/ASUS):

```sh
nvram get jffs2_exec
```

  Должно быть `/jffs/zapret-obkhod/autostart.sh`.

* если автозапуск не настроился, добавьте в раздел инициализации прошивки
  вручную одну строку:

```sh
/jffs/zapret-obkhod/zapret.sh boot
```

---

## Шаг 10. Как выключить или удалить

Временно выключить (интернет сразу вернётся в исходное состояние):

```sh
sh /jffs/zapret-obkhod/zapret.sh stop
```

Снять автозапуск:

```sh
sh /jffs/zapret-obkhod/zapret.sh autostart-off
```

Полностью удалить:

```sh
sh /jffs/zapret-obkhod/zapret.sh stop
sh /jffs/zapret-obkhod/zapret.sh autostart-off
rm -rf /jffs/zapret-obkhod
```

Системные файлы роутера при этом не трогаются.

## Если не работает

| Симптом | Что делать |
|---|---|
| `sh: can't open 'install.sh'` | Вы не в той папке. Сначала `cd /jffs/ZapretOBKHOD-router`. |
| `Permission denied` | Запускайте именно `sh install.sh`, не `./install.sh`. |
| `Exec format error` | Бинарник не подходит. Выполните `sh /jffs/zapret-obkhod/check.sh` и посмотрите раздел «Бинарники». |
| `iptables: not found` | В прошивке нет iptables. Нужен `iptables` (OpenWrt — доустановить). |
| Интернет пропал после включения | Сразу: `sh /jffs/zapret-obkhod/zapret.sh stop`. Затем попробуйте `preset soft`. |
| Сайты не открываются, но интернет есть | `sh .../zapret.sh preset all`, потом `preset youtube` — подобрать профиль. |
| Веб‑страница не открывается | `sh .../zapret.sh webstart`; проверьте `WEB_UI=1` в `config.sh`. |
| После перезагрузки не включается | См. шаг 9: JFFS и `jffs2_exec` / `rc_startup`. |
| Не пускает по SSH | На шаге 2 не включён SSH Daemon / SSHd. |

---

## Главные правила

1. **Не меняйте кабели и настройки WAN/LAN**, если интернет уже работает.
2. **Не ставьте галочку Clean JFFS** — она очистит раздел.
3. Не сообщайте никому пароль роутера и не открывайте веб‑интерфейс наружу.
4. Если что‑то пошло не так — команда `stop` возвращает iptables в исходное
   состояние. Это безопасно.
5. Трафик идёт напрямую через провайдера; VPN и внешние серверы не
   используются.
